# parallel_programming_labs

Лабораторные работы по курсу «Параллельное программирование».

| Работа | Тема |
| --- | --- |
| [Lab1](Lab1/README.md) | Последовательное умножение квадратных матриц, верификация NumPy и исследование времени выполнения |
| [Lab2](Lab2/README.md) | Умножение матриц с OpenMP, эксперименты по числу потоков |
| [Lab3](Lab3/README.md) | Умножение матриц с MPI, локальные эксперименты и задание для кластера |
| [Lab4](Lab4/README.md) | Умножение матриц на CUDA с блочным тайлингом |
| [Lab5](Lab5/README.md) | Параллельная генерация Мандельброта с `std::thread` по CS149 Program 1 |

Код лабораторной №3 проверен локально; запуск на кластере ещё ожидает настройки доступа и код проекта PBS. Для лабораторной №4 подготовлены CUDA-реализация и скрипт серии; запуск и замеры требуют доступного CUDA-компилятора и GPU.

[Задания курса](https://docs.google.com/document/d/1xfbPhD-x879jaVGjsjyDI_hHE0IXJW1dD5MqzyosBEk/edit).
