# Лабораторная работа №4 — CUDA

## Задание

Распараллелить матричное умножение из [Лабораторной №1](../Lab1/README.md) с помощью CUDA и измерить разные размеры задачи и конфигурации блоков.

## Реализация

В [main.cu](main.cu) реализовано умножение через shared-memory tiles размером `4 × 4`, `8 × 8`, `16 × 16` и `32 × 32`. Размеры матриц и сетки рассчитываются для выбранного tile; граничные элементы дополняются нулями, поэтому допустимы размеры, не кратные стороне блока. Программа сообщает модель GPU, время ядра и время полного вычисления, записывает матрицу и проверяется относительно NumPy `A @ B`.

## Сборка и эксперименты

На машине с совместимыми `nvcc` и NVIDIA GPU:

```bash
make
make example
make experiments
```

Серия включает размеры `200, 400, 800, 1200, 1600, 2000`, четыре конфигурации блока, один прогрев и пять замеров. Скрипт [cuda_experiments.py](cuda_experiments.py) сохраняет параметры устройства, сырые результаты, медианы и графики. Для запуска на GPU-узле кластера подготовлен [PBS-шаблон](templates/run_cuda_experiments.pbs); в нём нужно подставить код проекта и проверить доступный модуль CUDA.

В текущем рабочем окружении есть Apple M4, но нет `nvcc` и NVIDIA GPU. Поэтому исходник и скрипт подготовлены, а компиляция и экспериментальные результаты должны быть получены на CUDA-узле; в репозитории не подменяются фиктивными замерами с CPU.
