# Лабораторная работа №4 — CUDA

## Задание

Распараллелить матричное умножение из [Лабораторной №1](../Lab1/README.md) с помощью CUDA и измерить разные размеры задачи и конфигурации блоков.

## Реализация

В [main.cu](main.cu) реализовано умножение через shared-memory tiles размером `4 × 4`, `8 × 8`, `16 × 16` и `32 × 32`. Размеры матриц и сетки рассчитываются для выбранного tile; граничные элементы дополняются нулями, поэтому допустимы размеры, не кратные стороне блока. Программа сообщает модель GPU, время ядра и время полного вычисления, записывает матрицу и проверяется относительно NumPy `A @ B`.

## Сборка и эксперименты

Локально на машине с совместимыми `nvcc` и NVIDIA GPU:

```bash
make
make example
make experiments
```

Серия включает размеры `200, 400, 800, 1200, 1600, 2000`, четыре конфигурации блока, один прогрев и пять замеров. Скрипт [cuda_experiments.py](cuda_experiments.py) сохраняет параметры устройства, сырые результаты, медианы и графики. Для кластерной серии используется Slurm-скрипт ниже.

Для кластера «Сергей Королёв» подготовлены [скрипт отправки](submit_on_cluster.sh) и [Slurm-скрипт](run_on_cluster.sbatch). Скрипт задания запрашивает один GPU через `--gres=gpu:1`, собирает программу на вычислительном узле с `cuda/8.0` и запускает её на Tesla M2070 (`sm_20`):

```bash
./submit_on_cluster.sh
squeue -u "$USER"
```

Кластерный запуск не требует Python 3 или NumPy на GPU-узле: Bash/awk-скрипт генерирует детерминированные целочисленные матрицы, проверяет каждый размер блока сравнением результата с блоком `4 × 4` и сохраняет сжатый эталонный файл. После завершения скачайте папку результатов на машину с NumPy и выполните независимую проверку:

```bash
python3 ../tools/verify_cluster_matrix_results.py --program cuda --results-dir results/sergey-korolev
```

Кластерные замеры и проверка NumPy должны быть записаны в `results/sergey-korolev`; результаты локального устройства не подменяют замеры NVIDIA GPU.

## Результаты на кластере

Полная серия выполнена 16 октября 2026 года на `n243.ssc`, GPU Tesla M2070, с CUDA 8.0: шесть размеров, блоки `4 × 4`, `8 × 8`, `16 × 16`, `32 × 32`, один прогрев и пять замеров на конфигурацию. Все 120 измеренных матриц побайтно совпали с результатом блока `4 × 4`; шесть эталонных выходов прошли независимую проверку NumPy (`rtol=1e-9`, `atol=1e-9`, максимальная абсолютная ошибка `0`). Данные, журналы и график находятся в `results/sergey-korolev`.

Для `n=2000` лучший результат дал блок `16 × 16`: медианное время ядра `0.170 с` против `1.211 с` у `4 × 4`, то есть `7.14×`. Полное время с выделением памяти и копированием данных уменьшилось с `3.653 с` до `2.663 с` (`1.37×`), поэтому отдельно приведены время ядра и сквозное время.
