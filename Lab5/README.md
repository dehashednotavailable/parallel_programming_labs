# Лабораторная работа №5 — параллельная генерация множества Мандельброта

## Задание

Выполнить одну программу из [Stanford CS149 Assignment 1](https://github.com/stanford-cs149/asst1) по требованиям соответствующего задания. Выбрана программа 1: параллельная генерация фрактала с помощью `std::thread`.

## Реализация

`main.cpp` строит два изображения размером `1600 × 1200` с пределом в 256 итераций для каждого пикселя. Перед запуском параллельного варианта вычисляется последовательный эталон; после выполнения изображения сравниваются попиксельно. Потоков создаётся `N - 1`, а главный поток тоже обрабатывает свою долю.

Сравниваются два способа распределить строки:

- `blocks` делит изображение на непрерывные блоки строк, как в начальной постановке задания. Внутри строк вычислительная стоимость разная, поэтому время потоков может сильно отличаться.
- `cyclic` статически отдаёт потоку строки `thread_id, thread_id + N, ...`. Соседние строки, требующие похожего числа итераций, попадают разным потокам; блокировки и обмен данными не нужны.

Режим `cyclic` применяется ко всем числам потоков одним правилом. В отчёт включены измерения времени каждого потока, ускорение для обоих видов, начальное блочное распределение для сравнения, а также запуск с 16 потоками.

## Сборка и запуск

```bash
make
make check
./mandelbrot --view 1 --threads 8 --partition cyclic
```

При обычном запуске выполняются пять внутренних повторов и берётся минимальное время, как в оригинальной программе. Аргумент `--image-prefix` сохраняет изображения в формате PGM. Для полного набора измерений:

```bash
make experiments
```

В `results/raw.csv` записаны все повторы, а в `results/summary.csv` — медианы и ускорения. `results/speedup.png` и `.svg` показывают ускорение для первого вида, `results/images/` содержит последовательное и параллельное изображения. Окружение зафиксировано в `results/environment.json`.

## Эксперимент и выводы

Полная серия выполнена на Apple M4 (10 логических CPU) с Apple Clang 17. Для каждого режима и числа потоков было три независимых запуска; внутри каждого процесса брались минимумы из пяти рендеров. Все изображения во всех конфигурациях совпали с последовательным эталоном попиксельно.

Изображение первого вида, построенное циклическим распределением на восьми потоках:

![Множество Мандельброта, вид 1](results/images/view1-cyclic-8-threaded.png)

На первом виде блочное разбиение дало `3.73×` на восьми потоках, а циклическое — `5.70×`. Восемь блочных работников затратили на свои доли времени с отношением максимума к минимуму `18.1`; при циклическом разбиении это отношение снизилось до `1.14`. Для второго вида ускорение циклического разбиения составило `5.34×` на восьми потоках. При 16 потоках получено `6.36×` для первого вида и `6.00×` для второго — примерно на 12% лучше восьми потоков. Эти результаты показывают балансировку статического циклического распределения; ожидаемые в задании 7–8× на данном Mac не достигнуты, поэтому приводятся фактические числа, без переноса результатов на целевую машину Stanford.

Замер включает построение изображения, создание потоков и ожидание их завершения, но исключает сохранение файлов. `worker_min_seconds` и `worker_max_seconds` измеряют вычисление у каждого потока в самом быстром из внутренних повторов; они помогают отделить дисбаланс разбиения от общей пропускной способности процессора.
